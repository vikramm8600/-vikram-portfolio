# Vikram Vadhera — Personal Portfolio

Responsive portfolio website featuring your profile photo, project links, project search and filters, light/dark mode, and a portfolio chatbot interface.

## Features
- Home, About, Skills, Projects, and Contact sections
- Personal photo at `assets/vikram-profile.jpg`
- Responsive desktop and mobile layout
- Search projects by name or technology
- Category filters, light/dark mode, and chatbot interface
- Vercel serverless chatbot endpoint with server-side API configuration

## Deploy
Import this repository into Vercel. If the files are inside a subfolder, set that folder as the Root Directory. To enable live AI responses, configure `CHATBOT_API_URL`, `CHATBOT_API_KEY`, and optionally `CHATBOT_MODEL` in Vercel Environment Variables. Never put secret API keys in public frontend files.
